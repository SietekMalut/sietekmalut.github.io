Buat feed baru

Tempel alamat halaman yang ingin dijadikan feed. Sistem akan mengambil judul, tanggal, ringkasan, dan gambar dari halaman itu, lalu menerbitkannya sebagai XML.

Boleh halaman beranda, kategori, atau URL feed RSS/Atom yang sudah ada.

Tidak ada data yang dikirim ke mana pun sampai Anda menekan tombol GitHub di bawah.

Permintaan siap

Langkah terakhir: kirim ke repositori. Setelah itu robot GitHub membuat XML-nya dalam 1–2 menit.

slug https://sietekmalut.github.io/feeds/slug.xml
Buka GitHub & publikasikan

Butuh login GitHub (akun SietekMalut). Di halaman GitHub, tekan Commit changes — tidak perlu mengubah apa pun.

Lihat isi permintaan

Kalau tombol GitHub tidak bisa dipakai

  1. Buka halaman Actions, tekan Run workflow.
  2. Isi url dan name, lalu jalankan.
  3. Tunggu ikon centang hijau; link feed muncul di katalog ini.

Batas yang wajar

  • Halaman yang butuh login atau dirender penuh oleh JavaScript tidak bisa dibaca.
  • Situs yang menolak robot (403/429) akan gagal; feed lama tetap dipertahankan.
  • Feed diperbarui otomatis tiap 30 menit.

Cara pakai

  1. 1

    Pilih atau buat feed

    Gunakan feed yang sudah ada, atau buat baru dengan menempel satu alamat halaman.

  2. 2

    Salin link XML

    Bentuknya selalu https://sietekmalut.github.io/feeds/nama-feed.xml.

  3. 3

    Tempel di pembaca RSS

    Feedly, Inoreader, NetNewsWire, FreshRSS, atau widget dashboard — semuanya bisa membaca RSS 2.0. Butuh data untuk scraping? Pakai versi .json (JSON Feed 1.1).

  4. 4

    Biarkan berjalan

    Robot GitHub memperbarui XML tiap setengah jam. Link tetap sama, isinya yang bertambah.

Apakah ini benar-benar gratis dan permanen?

Ya, selama repositori GitHub Pages-nya ada. Tidak ada langganan, database, atau server yang perlu dinyalakan.

Kenapa halaman saya menghasilkan feed kosong?

Biasanya karena daftar artikelnya dibuat oleh JavaScript, atau situs memblokir permintaan otomatis. Coba alamat halaman kategori/indeks yang memuat tautan artikel langsung di HTML.

Apakah saya bisa memakai lebih dari 100 item?

Tidak untuk saat ini. Batas 100 item menjaga ukuran file dan waktu muat tetap wajar. Untuk arsip, gunakan beberapa halaman kategori.

Bagaimana kalau situsnya mati sementara?

Generator tidak menghapus feed lama. File XML terakhir tetap bisa diakses, dan akan diperbarui lagi saat situs pulih.
